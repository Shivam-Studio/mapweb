# Bundled MapMotion Studio starter maps

This folder contains 10 built-in map assets: World Map — India View, World Satellite Map — India View, World Physical Map — India View, Asia, Europe, Africa, North America, South America, Oceania, and India & Neighbours.

`world-satellite-india-view/` bundles the supplied corrected 2048×2048 SVG (with its embedded satellite raster and 257 editable boundaries) plus the supplied 2048×2048 physical PNG as an embedded Physical style layer. Both supplied source assets are preserved on the same 2048×2048 canvas. The geographic projection and redistribution license were not independently verified; confirm rights before publishing the public repository.

The editable country-boundary data is based on the user-supplied amCharts world SVG and is provided under CC BY 4.0 with the required **Map by amCharts** credit. Region packs are adapted/cropped versions of this source. See `ATTRIBUTION.md` for source and license links.

The physical-relief overlay is illustrative project-generated artwork, not measured elevation data. The `world-satellite-india-view/` starter pack includes user-supplied satellite imagery embedded in its SVG; the separate physical PNG is also user-supplied. Their redistribution rights and geographic projection have not been independently verified.

These starter assets are tracked in Git and are read-only deployment assets. User uploads remain in runtime storage and should not be committed.
